# ig-archiver-template

인스타 게시물 소장 페이지 템플릿 — 폰 공유 버튼 한 번으로 내 GitHub Pages에 게시물이 자동 저장됩니다.

- **폴더 기능**: 저장할 때 폴더 이름을 입력하면 카테고리로 분류되고, 페이지 상단에서 폴더별 필터가 됩니다 (새 폴더는 저장할 때 이름을 쓰는 것만으로 자동 생성)
- **작동 방식**: GitHub Actions(무인 자동실행)가 Apify로 게시물 정보를 수집 → 페이지 재생성 → 자동 발행
- **열람 주소**: `https://<내깃허브아이디>.github.io/ig-archive/` (검색엔진 차단, 주소 아는 사람만 접근)
- **사용법**: 이 템플릿을 복제한 뒤 세팅하는 전체 안내는 별도 문서(AI지시서)를 참고하세요

## 폴더 구조

```
├── .github/workflows/save.yml   # 자동 실행 작업표
├── scripts/collect.py           # 게시물 수집 (Apify)
├── scripts/build.py             # 페이지 재생성 (폴더 필터 포함)
├── data/                        # 저장된 게시물 기록 (폴더별 하위 폴더)
│   └── 미분류/                  # 폴더 지정 없이 저장하면 여기로
└── site/                        # 생성된 웹페이지 (수정 금지 — 자동 생성됨)
```

- `data/` 안의 JSON은 캡션·좋아요·댓글 텍스트의 영구 기록입니다 (이미지 주소는 만료되어 미저장)
- 페이지 화면을 꾸미고 싶으면 AI에게 `scripts/build.py`를 보여주고 수정을 요청하세요
